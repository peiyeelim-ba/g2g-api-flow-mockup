Self-serve API verification flow replacing manual BD approvals

BRD Owner: Jason  ·  Stakeholders: Jason, Thomson, Rui Jun, Vava, Alfred  ·  Status: Draft for review

Context. Today, BD manually approves API access for all categories without proof of integration — sellers then enable "Instant Delivery" without writing a single line of code, leading to orders stuck in "Delivering" and CTO manual intervention. This proposal replaces that with a self-serve flow: sellers must create a locked Test Offer, purchase it from a secondary account, and only after a successful API delivery payload is received does "Instant Delivery" unlock across all their offers.
